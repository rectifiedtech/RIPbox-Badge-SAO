Scope of project
Startup
    -The logo LED needs to always be on unless it receives message or gets pinged by another ripbox.
    -ESPnow needs to always be running in the background to allow other ripboxes to discover them, ping them, and send messages to them. When a ripbox is pinged then it needs to flash the led logo over and over and display a "Kiosk ID XX just pinged you" until the user presses a button, when a message is received by another ripbox then the logo led needs to flash over and over and display "New msg from kiosk ID XX, push to view" then when any button is pressed it will display the message and save it to flash memory where it can be read again later with the kiosk id number associated with the message.
    -Display ripbox logo with kiosk ID number (this number is a three digit number that needs to be stored in the flash memory and the default is 999, make a note in the code as to which exact memory address this is stored at for future reference).
    -Default to redbox animations and rental animations.
    -Pressing either button separately opens the rental menu.
    -Pressing both buttons brings up the secret menu at any time.

Redbox rental animations
    -Cycle through generic ads for renting movies (until either button is pressed).
    -Pressing any button brings up the rental menu.

Rental menu
    -selectable list of movie rentals (refer to movie list).
    -use left button to scroll through the movie list and right button to select movie.
    -when movie is selected then show a fictious price and the left button goes back and the right button goes to a fictious payment process and animation when purchased.

Secret menu
    -List of applications (kiosk id number at top right of screen - only two digits)
        --Messages - Displays a list of messages from other kiosks with their kiosk id and number incoming messages starting with "1".
        --Scan for kiosk - this menu option will open another menu that will automatically scan for other ripboxes and allows the user to select as kiosk id in range.
            ---Send Message - this will bring up a basic text editor that allows the user to type out their message using the left button to select the letter or number and the right button will type the selected number, pressing and holding the left button will type a space character, pressing and holding the right button will send the message and and verify whether the message was received or not by the other device.
            ---Ping Kiosk - this will ping the selected kiosk ID in range.
        --Games
            ---Tetris style game
            ---Flappy bird style game
            ---Block breaker style game
        
        
        







#PROMPT

Write some arduino code for the an esp8266 that has the following specifications:

The application is for a PCB SAO (simple add-on) badge for the 2026 hackaday superconference that is a Redbox kiosk shaped pcb with two buttons, a 64x48 ssd1306 OLED display, and an LED at the top to light up the logo.
This is a Redbox that is being rebranded as RIPbox to commemorate the defunct company Redbox that went out of business, this badge also has lots of other features mentioned in detail.

The ESP8266 is configured with the following pins:
GPIO 12 - Button 1 (left button, or select button), requires internal pullup resistor to be enabled.
GPIO 13 - Button 2 (right button, or enter button), requires internal pullup resistor to be enabled.
GPIO 14 - Logo LED, pull high to turn on.
Display - SSD1306 64x48 OLED display - i2c address 0x3c (this is a very small display, please make sure text actually fits on the screen, even if you need to use a very small font).
Use the U8g2 library for the screen and graphics and make sure to optimize for very low flicker on animations.
#include <U8g2lib.h>

U8G2_SSD1306_64X48_ER_F_HW_I2C u8g2(
  U8G2_R0,
  U8X8_PIN_NONE
);
